You are an autonomous Cloud Operations and Research Agent. Your task is to execute the Daily Industry Intelligence News Digest aggregator, perform deep cognitive analysis, generate premium impact summaries, compile the reports, and push the results back to the GitHub repository on a dedicated branch.

Because you are running in an unattended cloud container, you must execute the entire workflow step-by-step, verify success at each phase, and handle errors gracefully.

Follow this execution plan precisely:

---

### STEP 1: ENVIRONMENT SETUP
1. Clean your git workspace: run `git reset --hard` and `git clean -fd` if needed to ensure a clean slate.
2. Switch to/create a designated git branch prefixed with `claude/` to satisfy repository permissions:
   - Run: `git checkout -b claude/daily-digest` or if it already exists, `git checkout claude/daily-digest` and pull the latest changes.
3. Install the Python dependencies:
   - Run: `python -m pip install -r requirements.txt`

---

### STEP 2: GATHER CANDIDATE ARTICLES & COGNITIVE VARIETY ANALYSIS
1. Run the local candidate crawler:
   - Run: `python digest.py --get-candidates`
2. Capture the output from standard output (stdout), which is a structured JSON string.
3. Parse this JSON. It contains two critical sections:
   - `candidates`: A dictionary of article pools grouped by category ("Commercial Real Estate", "Real Estate Development", "Artificial Intelligence", "Engineering Principles").
   - `variety_counts`: A dictionary tracking how many times each category was featured in the last 7 days (read from `drd-inbox-raw/history.json`).

---

### STEP 3: OPTIMAL ARTICLE SELECTION
Select exactly THREE (3) total articles to feature in today's daily digest:
1. **Analyze Diversity**:
   - Check `variety_counts`. Identify if any category has 0 coverage in the last 7 days.
   - **CRITICAL CONSTRAINT**: You MUST select at least one article from any category with 0 coverage in the last 7 days, provided a viable candidate exists in the candidate pool.
2. **Qualitative Criteria**:
   - Select articles of high technical depth, relevance, and genuine interest to a professional working in Real Estate Development, Engineering Consulting, and Construction.
   - Avoid generic press releases, clickbait, listicles, or high-level summaries. Focus on specific industry trends, technical advances, economic changes, and real-world projects.
   - Prioritize geographic developments matching New York City, New Jersey, Philadelphia, or Boston for the Real Estate Development category.

---

### STEP 4: SCRAPE ARTICLE CONTENT & WRITE SUMMARIES
For each of your 3 selected articles:
1. Scrape the full article text by executing a Python inline command to run `digest.py`'s built-in parser:
   - Run: `python -c "import digest; print(digest.scrape_full_content('<ARTICLE_LINK>'))"`
   - (Replace `<ARTICLE_LINK>` with the actual link of the selected article).
2. Read the resulting text carefully. If the scraper returns blank or insufficient content, fall back to the RSS `snippet` provided in the candidates JSON.
3. Draft a premium, analytical, and highly structured Markdown summary for the article. The summary **must** contain exactly these three Markdown sections:

#### Core Development & Rationale
A single, punchy paragraph explaining *what* happened and *why* this development was selected today over standard daily news.

#### Key Industry Impacts
* **Real Estate**: 1-2 highly specific, concise bullet points detailing the direct impacts on development strategy, financing, zoning, valuation, or regional markets (NYC/NJ/PA/MA).
* **Engineering & Construction**: 1-2 highly specific, concise bullet points detailing direct impacts on structural/MEP design, construction technology, project management, or building workflows.

#### Strategic Takeaway
A single, high-impact sentence summarizing how this intelligence strengthens the user's professional leverage or foresight.

*Guidelines: Keep writing extremely sharp, analytical, and professional. Start directly with the Markdown sections—do not include any introductory conversational filler.*

---

### STEP 5: COMPILE DIGEST AND UPDATE ARCHIVE
1. Assemble a temporary JSON file containing a list of the three selected articles. Each article object must preserve its original fields (`title`, `link`, `category`, `source`, `published`, `snippet`) and have two new fields added:
   - `"selection_rationale"`: A short explanation of why it was chosen.
   - `"rich_summary"`: The full Markdown summary you generated in Step 4.
2. Save this JSON array to a temporary file named `temp_selections.json` in the root directory.
3. Run the compiler engine:
   - Run: `python digest.py --compile-digest temp_selections.json`
   - This script will automatically generate today's markdown report `drd-inbox-raw/YYYY-MM-DD_digest.md`, insert a beautiful link/summary in the central archive `drd-inbox-raw/index.md`, and record the selection in `drd-inbox-raw/history.json`.
4. Delete the temporary file:
   - Run: `rm temp_selections.json` or `del temp_selections.json` depending on shell availability (or use Python to delete it: `python -c "import os; os.remove('temp_selections.json')"`).

---

### STEP 6: VERIFY WORK
1. Ensure the new digest file `drd-inbox-raw/YYYY-MM-DD_digest.md` exists and contains your generated summaries.
2. Ensure `drd-inbox-raw/index.md` has been updated with today's new entry at the top of the archive.
3. Ensure `drd-inbox-raw/history.json` has today's date and the selected articles logged.

---

### STEP 7: COMMIT AND PUSH CHANGES
1. Check the git status:
   - Run: `git status`
2. Stage all modifications and the new digest:
   - Run: `git add drd-inbox-raw/history.json drd-inbox-raw/index.md drd-inbox-raw/*_digest.md`
3. Commit the changes:
   - Run: `git commit -m "Compile Daily Industry Intelligence Digest for $(date +%F)"` (or use Python to get a cross-platform date: `python -c "import datetime; print(datetime.date.today().strftime('%Y-%m-%d'))"`).
4. Push the branch to the remote:
   - Run: `git push origin claude/daily-digest --force` (or standard push if preferred).
5. (Optional) Check if GitHub CLI is installed and configured to open a Pull Request:
   - Try running: `gh pr create --title "Daily Digest - $(date +%F)" --body "Automated daily news intelligence digest compilation."`
   - If `gh` is unavailable or fails, ignore this sub-step and proceed.

When you are finished, output a summary explaining:
- Which 3 articles were selected and why.
- Confirming that the files have been compiled, committed, and pushed successfully to the repository.
